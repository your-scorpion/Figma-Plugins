# GeoJSON line importer

Plugin identity:
- displayName: GeoJSON line importer
- description: Converts GeoJSON, KMZ, and Shapefile geometry into editable vector lines in Figma

Original user prompt:
Create a plugin that, I have an geojson, 24.6670605933794 ], [ 54.654238309742098, 24.667060209252199 ], [ 54.654240060456203, 24.667058643855899 ], [ 54.654239957812699, 24.6670584097809 ], [ 54.6542408534388, 24.6670578073889 ], [ 54.654240874970696, 24.667057792906601 ], [ 54.654240922337401, 24.667057761048099 ], [ 54.654240926351399, 24.6670579628944 ], [ 54.6542409263933 amd so on, and I want to convert it into vector line in figma

Usage:
Upload a valid .geojson, .json, .kmz, or .shp file, choose the maximum output size, stroke width, and stroke color, then create editable vector lines. GeoJSON supports FeatureCollection, Feature, GeometryCollection, LineString, MultiLineString, Polygon, and MultiPolygon. KMZ supports KML line strings, rings, and tracks. Shapefile supports PolyLine and Polygon records, including Z and M variants.
